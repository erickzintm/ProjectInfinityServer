# Visão do Projeto

## Objetivo

Criar o melhor servidor brasileiro de Project Infinity.

O foco não será apenas completar o modpack, mas construir uma economia viva, baseada na interação entre jogadores.

## Princípios

- Economia criada pelos jogadores.
- Progressão longa.
- Zero Pay to Win.
- Sistemas próprios.
- Multilíngue.
- Atualizações constantes.

## Diferenciais

- Empresas.
- Banco.
- Mercado livre.
- Sistema de contratos.
- Tradução completa.
- Sistema de idiomas.
